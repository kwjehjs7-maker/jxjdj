# SO2 Match Tracker — Android

Нативное приложение на Kotlin, Jetpack Compose и Room. Целевая версия — Android 14 (API 34) и новее; сборка настроена на Android 16 (API 36).

## Сборка APK

APK в этой среде не собран: здесь не установлены Java/JDK и Android SDK. Исходный проект подготовлен для сборки в Android Studio.

1. Установи Android Studio актуальной версии с поддержкой Android SDK 36.
2. В **SDK Manager** установи **Android 16 (API 36)** и соответствующие Android SDK Build-Tools.
3. Открой в Android Studio папку `android` этого проекта — ту, в которой находится `settings.gradle.kts`.
4. В настройках Gradle выбери **Gradle JDK 17** (подойдёт встроенный JDK Android Studio). Дождись синхронизации проекта и разреши загрузку Gradle и библиотек из Google Maven и Maven Central. Интернет нужен только для первой сборки; готовое приложение его не использует.
5. Выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Android Studio сохранит отладочный APK здесь:

   `android/app/build/outputs/apk/debug/app-debug.apk`

Для сборки из терминала на компьютере с JDK 17 и Android SDK 36:

```bash
cd android
./gradlew :app:assembleDebug
```

В Windows используй `gradlew.bat :app:assembleDebug`.

Перед сборкой APK можно запустить unit-тесты расчётов:

```bash
./gradlew :app:testDebugUnitTest
```

## Установка на телефон

1. Перенеси `app-debug.apk` на телефон.
2. Открой APK в файловом менеджере.
3. Если Android попросит разрешение, разреши установку приложений из этого источника и повтори установку.
4. Запусти **SO2 Match Tracker**.

## Что хранится и как делается резервная копия

- Матчи хранятся в локальной базе Room `so2-match-tracker.db`.
- Приложение не запрашивает интернет, аккаунт или разрешение на запись экрана.
- Экспорт создаёт JSON-файл через системный диалог выбора места.
- Перед импортом приложение проверяет версию, типы и пределы полей всего файла. Ошибка хотя бы в одной записи отклоняет файл целиком.
- Импорт показывает подтверждение и добавляет только новые идентификаторы. Совпадающие записи пропускаются; старые матчи не перезаписываются и не удаляются.
- У базы нет destructive migration fallback. При расширении схемы в следующих версиях нужно добавить явную Room-миграцию, чтобы сохранить данные.

## Проверка

В `app/src/test` находятся unit-тесты расчётов: суммарный K/D, ноль смертей, доля побед, сумма MMR, доля категорий и скользящий процент побед. Они написаны, но в текущей среде не запускались: отсутствуют Java/JDK и Android SDK.

После сборки проверь на устройстве:

- сохранение матча, принудительное закрытие приложения и запуск снова;
- общий K/D на матчах с нулём смертей;
- изменение и подтверждённое удаление записи;
- экспорт, импорт новой копии и повторный импорт без перезаписи;
- основные поля и цифровую клавиатуру на узком экране.

## Ограничения текущей версии

- APK не приложен, потому что сборочная среда не содержит Android toolchain.
- Испытание установки и работы на Redmi Turbo 4 Pro / Android 16 не проводилось.
- Интерфейс и Android-проект готовы к сборке, но тесты и сборку необходимо выполнить на компьютере с Android Studio.
